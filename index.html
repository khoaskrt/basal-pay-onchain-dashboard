Nguồn dữ liệu

BSC: tải miễn phí qua NodeReal, không cần key. Polygon và các chain khác: qua Etherscan API V2, cần key miễn phí. Key chỉ lưu trên máy này và chỉ gửi tới api.etherscan.io.

Money flow

Trái → phải: nguồn tiền vào → chain (inflow) → Central Vault đang chọn → chain (outflow) → nơi nhận. Độ dày dải = giá trị.

Chưa có dữ liệu. Nhập API key và bấm “Tải dữ liệu on-chain”, hoặc import CSV.

Theo thời gian

Cột trên trục 0 = inflow, dưới trục 0 = outflow, xếp chồng theo chain. Bấm vào một cột để xem Sankey của kỳ đó.
